La ruta M–D–A–I

Cuatro eslabones que una tesis recorre en orden. Cada uno impone un techo a lo que se puede concluir, y ninguno se repara en el capítulo de discusión.

M

Medición

¿Qué atributo, en qué unidad y con qué evidencia de calidad? El coeficiente se elige por la naturaleza del dato.

D

Diseño

¿Contra qué se comparó? El diseño se nombra por la comparación ejecutada, no por la etiqueta.

A

Análisis

¿Cuánto y con qué precisión? Magnitud en unidades originales, con su intervalo.

I

Interpretación

¿Qué verbo corresponde? «Se observó», «se estimó» o «se atribuye», según el nivel alcanzado.

El nivel de la conclusión es el del eslabón más débil: L* = min(LM, LD, LA)

Reproducir una cifra

Toda cifra tiene tres referencias: el caso, el guion y el archivo de datos. Los escenarios son sintéticos, con semilla 20261103 y manifiesto SHA-256.

Python

# regenerar los datos
python codigo/python/generar_datos_casos.py
python codigo/python/generar_casos_tecnicos.py

# verificar contra el manifiesto SHA-256
python codigo/python/verificar_escenarios.py

# un caso concreto
python codigo/python/analisis_M07.py

R

# paquetes (solo para dos guiones)
source("codigo/r/00_instalar_paquetes.R")

# todos los análisis
Rscript codigo/r/run_all.R

# el caso con datos reales (KC1, NASA)
Rscript codigo/r/04_datos_publicos.R
Datos sintéticos, declarados. Ningún escenario proviene de una institución real; reproducen patrones observados en el corpus de 124 tesis. El caso U-10 usa datos públicos de la NASA (KC1, PROMISE). No hay datos personales en el repositorio.
